# Banque d'éléments shuimo — prompts Nano Banana

Une planche par prompt, déposée ici sous le nom indiqué (`01_lointain.png`, …). Générer d'abord la
planche 02, puis la donner en image de référence pour les autres (« same ink style, same light »).
Chaque planche : éléments séparés par de larges espaces blancs, rien ne se touche, fond blanc pur.

## Bloc de style commun (en tête de chaque prompt)

```
Contemporary Chinese ink-wash art, modern minimalist shuimo: clean graded ink washes from deep black to pale pearl grey, soft wet edges bleeding into white, simplified sculptural forms, calm and airy. Not an antique painting: no texture strokes, no aged paper, no calligraphy, no seals, no signature, no frame, no border.
Pure flat white background (#FFFFFF), no paper texture, no vignette, no shadows, no ground line. Every element fully visible, none cropped by the image edge. Landscape 3:2, high resolution.
```
