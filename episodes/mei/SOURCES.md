# 美 — sources et points à vérifier

- **Shuowen jiezi** (Xu Shen, vers 100) : 「美，甘也。从羊，从大。羊在六畜主給膳也。美與善同意。」
- **Xu Xuan** 徐鉉, édition du Shuowen (986, dynastie Song) : 「羊大則美。」
- **小學堂** (formes anciennes, CC0) : `glyphes/mei_xiaoxue/` (12 formes : 3 os Shang, 美爵 Zhou de l'Ouest,
  中山王壺 Royaumes combattants (Jin), petit sceau, 睡虎地 et 五十二病方 (Qin), 老子乙前 (Mawangdui, Han de l'Ouest),
  夏承碑, 熹平石經, 曹全碑 (Han de l'Est)). Aucune forme de Chu : à Chu, « beau » s'écrit 媺 (voir ci-dessous).
- **羌** (小學堂 / Shuowen 「西戎牧羊人也」) : homme coiffé de cornes de mouton ; captifs Qiang sacrifiés par les Shang.
- **Guodian** 郭店 (Jingmen, Hubei ; fouillée en 1993 ; tombe de Chu ≈ 300 av. J.-C.) : Laozi A, passage
  « 天下皆知美之為美也，惡已 » ; « beau » y est écrit d'une graphie notée 媺 (= 美) par les transcriptions courantes
  (source secondaire : zhuanlan.zhihu.com/p/8962711860 ; ctext.org/guodian). **À vérifier sur l'édition** de 1998.
- **Mawangdui** 馬王堆 (fouillée en 1973 ; tombe 3, 168 av. J.-C.) : Laozi B sur soie, 美 avec 羊 (forme `08`).
- **Lu You** 陸游, 《老學庵筆記》 卷八 : 「蘇文熟，喫羊肉；蘇文生，喫菜羹。」
- **美國** : transcription de 亞美利加 (Amérique) ; japonais 米国 (亜米利加).

## Fait / hypothèse / légende
- **Fait** : Shuowen 甘也 从羊从大 ; Xu Xuan 羊大則美 ; 羌 à cornes de mouton ; Laozi de Guodian et de Mawangdui ; dicton
  de Lu You ; 美國 = transcription.
- **Hypothèse** : coiffe de plumes (danseur paré) ou de cornes sur les formes Shang (lectures modernes, ex. 李孝定,
  蕭兵 « 羊人為美 ») ; « les deux à la fois » (homme paré de cornes de mouton) = synthèse de l'épisode, à présenter
  comme « sans doute ».
- **À vérifier** : graphie exacte de Chu (媺 ou variante, présence de 女) ; emploi de 美 dans les os (nom propre).
